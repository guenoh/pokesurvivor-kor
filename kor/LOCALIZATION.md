# 한국어 표현과 폰트

영문판의 화면 문구를 기준으로 한국어 게임 문체에 맞춰 옮겼습니다. 별도 출시된 공식 한국어판을 뜻하지 않습니다.

## 표현 원칙

- 포켓몬·기술·도구·특성·성격은 PokeAPI 한국어 명칭을 우선합니다. 성격 진단의 성향과 배틀 능력치에 영향을 주는 성격은 별개입니다.
- `Shiny`는 ‘색이 다른 포켓몬’, 치명타는 ‘급소’, 전투에서 상대를 물리치는 행위는 ‘쓰러뜨리기’로 표현합니다.
- 플레이어의 쓰러짐은 ‘기절’, 상대의 일시 정지는 ‘행동불가’로 구분합니다.
- 이름을 넣는 문장에는 받침에 맞는 조사를 적용합니다. 예를 들어 ‘피카츄가’, ‘잉어킹이’, ‘잠만보는’, ‘폴리곤은’으로 표시합니다.
- 카드 효과·기술 설명은 간결한 서술형, 메뉴와 시스템 안내는 존댓말, 성격 진단 선택지는 자연스러운 독백형으로 통일합니다.
- 재사용 대기시간·레벨 업 카드·기술 진화 등 이 게임 고유의 규칙을 원작 포켓몬의 PP나 진화 규칙으로 바꾸지 않습니다.
- 계정·저장·지원하지 않는 기능 안내는 독립판의 실제 동작에 맞춥니다. 과거 업데이트 기록은 원작 기록임을 명시합니다.
- 게임명, 제작자 이름, 권리자, 라이선스, 도메인, 키·컨트롤러의 실제 표기는 필요한 경우 유지합니다.

공식 문체 참고: [포켓몬스터스칼렛·바이올렛](https://www.pokemonkorea.co.kr/sv), [포켓몬 카드 게임의 상태 안내](https://pokemoncard.co.kr/info/html/sub07.html). 문장을 그대로 복사하지 않고 용어와 어조를 참고했습니다.

## 폰트

영문 로고·라틴 문자·숫자는 기존 Pixelify Sans를 유지하고, 한글에는 **Galmuri11**의 보통·굵은 글꼴을 사용합니다. 갈무리는 닌텐도 DS의 폰트 디자인에서 영감을 받은 픽셀 폰트입니다.

- 제작자: Lee Minseo (quiple)
- 출처: https://quiple.dev/font/galmuri
- 배포 저장소: https://github.com/quiple/galmuri
- 라이선스: SIL Open Font License 1.1
- 파일·라이선스: `assets/fonts/galmuri/`
- 커밋과 파일 해시: `kor/FONT-SOURCES.json`

DOM 메뉴와 Canvas 전투 표시 모두 한글 폰트를 사용합니다. 실행 전에 글꼴 로딩을 기다리며 외부 폰트 서버에 접속하지 않습니다.

## 검증

`kor/coverage.cjs`는 영어 기준 UI 사전 1,563개의 한국어 대응을 집계합니다. `tests/kor.test.cjs`는 변수 자리 수, 모든 포켓몬 이름, 특성·성격, 업데이트 기록, 성격 진단 성향을 검사합니다. 전체 문구의 의미와 화면 줄바꿈은 별도의 브라우저 검사로 확인합니다. 새 upstream 문구가 추가되면 한국어 대응을 추가해야 합니다.
