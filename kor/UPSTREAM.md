# Upstream 운영

원본 저장소 주소는 `JPTER78/pokesurvivor`, 추적 브랜치는 `main`입니다. 서버 저장소는 독립 구현이므로 원본 프런트엔드 커밋을 서버에 병합하지 않습니다.

`Daily upstream sync`는 매일 20:17 UTC(다음 날 05:17 한국 시간)에 실행됩니다. GitHub 스케줄은 지연될 수 있습니다. 공개 저장소가 장기간 비활성 상태이면 GitHub가 예약 실행을 끌 수 있으므로 Actions 상태도 확인하세요.

변경이 없으면 종료합니다. 변경이 있으면 현재 `main`에서 `sync/upstream`을 만들고 원본을 병합합니다. 생성물(`index.html`, `js/app.min.js`, `version.json`, `js/lang/*.js`)만 현재 판을 유지해 충돌을 해결합니다. 배포물은 CI와 배포 준비 단계에서 다시 생성합니다. 나머지 충돌은 파일 목록을 담은 이슈로 알리며 원본 코드나 한국어 코드를 임의로 버리지 않습니다.

PR은 자동 생성·갱신하지만 자동 병합하지 않습니다. 읽기 권한만 가진 CI가 명시적으로 실행되며 테스트와 빌드를 검증합니다. PR을 검토할 때 독립 API 연결, 한국어 파일, 라이선스·크레딧 변경, 새 외부 네트워크 연결을 확인하세요. 원본 업데이트 자체를 안전한 것으로 간주하지 마세요.

PR 병합은 배포를 시작하지 않습니다. `Manual production deployment`를 `main`에서 수동 실행하면 먼저 테스트·빌드로 해당 커밋의 배포물을 만든 뒤 `production` 환경 승인을 기다립니다. 배포 대상 미설정 상태에서는 승인하더라도 배포가 차단됩니다.
