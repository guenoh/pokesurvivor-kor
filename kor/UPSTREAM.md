# Upstream 운영

## 한국판 분리 경계

한국판의 서비스 구현은 `kor/`와 별도 Node/PostgreSQL 서버가 담당합니다. 한국어 문구는 `js/data/lang-ko*.js`, 스타일은 `kor/style.css`에서 관리합니다. 신규 한국판 기능을 원작 모듈에 통째로 덧붙이거나, 원작 파일 전체를 `kor/`에 복사해 유지하는 방식은 피합니다. 후자는 텍스트 충돌을 숨겨도 원작 개선을 놓치게 합니다.

현재 완전한 분리는 아닙니다. `upstream-boundary.json`에는 원작 소스 94개 중 직접 수정이 남은 32개를 등록했습니다. 각 항목은 이유, 연결된 한국판 모듈, 검토한 파일의 해시를 기록합니다. `node kor/upstream-boundary.cjs`는 Git 이력이 없는 소스 복사본에서도 등록되지 않은 원작 수정·새 소스·누락 파일과 검토하지 않은 패치 변경을 차단합니다. 이 검사는 파일 경계 검사이며 동작 호환성은 회귀 테스트로 별도 검증합니다.

일일 동기화는 원작 변경과 이 목록이 겹치는 부분을 PR 또는 충돌 이슈에 표시합니다. 원작 기준 해시는 새 커밋으로 갱신하지만 **한국판 패치의 검토 해시는 자동 갱신하지 않습니다**. Git이 자동 병합했더라도 해당 파일이 바뀌었다면 CI가 중단됩니다. 리뷰어는 연결 모듈과 관련 테스트를 확인한 뒤에만 `patches[path].reviewed`를 현재 파일의 SHA-256으로 갱신합니다. 기준 갱신만 필요할 때는 `node kor/upstream-boundary.cjs --refresh-baseline <upstream-commit>`을 사용합니다.

직접 수정한 기능을 옮길 때는 다음 순서로 줄입니다.

1. 슬롯 상태·랭킹 화면·도감 필터의 한국판 분기를 작은 상태 전달/어댑터 연결로 바꿉니다. 데이터 규칙과 렌더링 구현은 `kor/`가 맡습니다.
2. 게임 시작·갱신·종료의 확장 호출을 한곳으로 모으고, 아머드뮤츠의 전투·탄환·협동 메시지는 한국판 모듈로 옮깁니다. 원작의 비공개 상태를 다루는 부분은 먼저 동작 회귀 검사를 확보합니다.
3. 원작 HTML과 한국판 화면 삽입·설정값을 빌드 단계에서 합성해 `dev.html`의 직접 수정을 줄입니다. 생성물은 계속 CI에서 재생성합니다.

파일을 원작 그대로 돌려놓았으면 해당 패치 등록도 제거합니다. 해시 갱신으로 변경을 무조건 통과시키거나 계정·저장·랭킹 데이터를 변환해 충돌을 해결하지 않습니다. 완전히 분리한 뒤에도 원작 연결 규약이 바뀌면 호환성 수정이 필요할 수 있습니다.

원본 저장소 주소는 `JPTER78/pokesurvivor`, 추적 브랜치는 `main`입니다. 서버 저장소는 독립 구현이므로 원본 프런트엔드 커밋을 서버에 병합하지 않습니다.

`Daily upstream sync`는 매일 20:17 UTC(다음 날 05:17 한국 시간)에 실행됩니다. GitHub 스케줄은 지연될 수 있습니다. 공개 저장소가 장기간 비활성 상태이면 GitHub가 예약 실행을 끌 수 있으므로 Actions 상태도 확인하세요.

변경이 없으면 종료합니다. 변경이 있으면 현재 `main`에서 `sync/upstream`을 만들고 원본을 병합합니다. 생성물(`index.html`, `js/app.min.js`, `version.json`, `js/lang/*.js`)만 현재 판을 유지해 충돌을 해결합니다. 배포물은 CI와 배포 준비 단계에서 다시 생성합니다. 나머지 충돌은 파일 목록을 담은 이슈로 알리며 원본 코드나 한국어 코드를 임의로 버리지 않습니다.

PR은 자동 생성·갱신하지만 자동 병합하지 않습니다. 읽기 권한만 가진 CI가 명시적으로 실행되며 테스트와 빌드를 검증합니다. PR을 검토할 때 독립 API 연결, 한국어 파일, 라이선스·크레딧 변경, 새 외부 네트워크 연결을 확인하세요. 원본 업데이트 자체를 안전한 것으로 간주하지 마세요.

PR 병합은 배포를 시작하지 않습니다. `Manual production deployment`를 `main`에서 수동 실행하면 먼저 테스트·빌드로 해당 커밋의 배포물을 만든 뒤 `production` 환경 승인을 기다립니다. 배포 대상 미설정 상태에서는 승인하더라도 배포가 차단됩니다.

## 2026-10-26 통합 기준

`680c3e12c670a0f131ec846c43248372853389b1`까지 원작 커밋을 병합했습니다. 한국판 계정과 저장은 기존 Node/PostgreSQL API를 계속 사용합니다. 원작 Firebase 규칙·클라우드 랭킹을 한국판 서버에 배포하지 않습니다.

- 한국판의 협동 스냅샷 확장·보스 예고 보호·친구 필터를 원작 변경과 함께 유지합니다.
- 원작 방송 확인 워크플로는 원작 저장소에서만 실행되게 제한합니다. 한국판에서는 원작 크레딧을 유지하고 방송 상태를 주기 조회하지 않습니다.
- 백업 스키마 5는 피해량을 포함합니다. 이전 스키마 1~4 백업도 현재 복구 도구로 읽을 수 있으며 기존 기록의 피해량은 0으로 처리합니다.
