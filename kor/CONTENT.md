# 원작 콘텐츠 유지

한국판 추가 포켓몬·보스·기술·진화, 자체 포켓몬/기술 평가, 별도 특성·기술머신 화면과 모바일 메뉴 배치를 제거했습니다. 원작 포켓몬 966종과 기술 103종, 전투·보스·뽑기·강화 규칙 및 화면 배치를 사용합니다. 원작 할로윈은 유지합니다.

전투·탄환·스폰·심판·뽑기·업적에 한국판 콘텐츠를 삽입하지 않습니다. `module-source.cjs`는 원작 소스를 읽고 `service-adapter.cjs`의 독립 서비스 연결만 합성합니다. 어댑터는 협동 재연결의 relay 상태, 독립 서버의 방 시작, 랭킹 친구 범위 및 미지원 신고 기능을 다룹니다. 연결 문맥이 달라지면 빌드가 실패합니다.

`retired-content.js`는 콘텐츠를 등록하지 않는 저장 호환 코드입니다. 삭제된 ID 1150과 전용 기술의 참조를 정리하고 기존 정보를 `retiredKor` 아래 복구용으로 보관합니다. 다른 포켓몬에 강화나 보유분을 이관하지 않습니다. 선택 중인 동료는 이미 보유한 포켓몬으로 바꾸며 없으면 파트너 선택을 다시 합니다. 이 파일은 독립 서버 사본과 바이트 단위로 같아야 합니다.

아머드뮤츠 강화 비용 5배 보상은 서버의 종료 시점 저장·고정 비용표·지급 장부로 처리합니다. 프런트엔드 호환 코드가 코인을 생성하지 않습니다. 이미 지급한 보상은 재접속·재배포·이전 기기 저장·백업 복구로 다시 지급하지 않습니다. 전투 중 임시 기술 강화와 아이템 비용은 영구 강화 투자액에 포함하지 않습니다.
