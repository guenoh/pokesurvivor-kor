# 한국판 콘텐츠와 원작의 경계

원작 엔진 파일에 특정 포켓몬·기술의 ID, 수치, 진화 이름 또는 이벤트 분기를 추가하지 않습니다. 추가 콘텐츠는 데이터 팩, 동작은 한국판 모듈, 연결은 작은 빌드 어댑터로 관리합니다. 원작 엔진 파일 전체를 복사해 독립 버전으로 유지하지 않습니다.

## 현재 구조

- `content/*.json`: 추가 포켓몬·기술·진화·보스 설정·스프라이트 메타데이터. 새 JSON 팩은 자동으로 발견합니다.
- `content-packs.cjs`: 팩 형식과 팩 사이의 ID 중복 검사.
- `content-registry.js`, `register-species.js`: 원작 목록에 추가 등록. 원작 포켓몬·기술 ID 덮어쓰기는 거절합니다. 원작 기술의 레벨 강화·타입·피해량 계산은 계속 원작 구현을 사용합니다.
- `timed-rush.js`: 시간에 따라 이동하는 돌진과 유도탄 동작. 기술 데이터의 `controller`로 선택하며 특정 포켓몬·기술 ID를 판별하지 않습니다. 전용 습득 조건과 진화는 데이터의 `exclusiveDex`, `evolution`을 사용합니다.
- `armored-encounter.js`: 한국판 이벤트 보스 동작. 보스 설정은 데이터 팩에서 읽습니다.
- `content-runtime.js`: 화면·이벤트·협동 확장과 엔진 사이의 연결.
- `engine-adapter.cjs`: 빌드 메모리 안에서 작은 연결 코드를 삽입합니다. 원작 파일을 저장하거나 고치지 않습니다. 연결 문맥의 앵커가 정확히 일치하지 않으면 빌드를 중단합니다.
- `module-source.cjs`: 개발·배포·테스트·티어 생성·번역 검사에서 같은 모듈 조합을 사용합니다. 단위 테스트의 `isolatedSource`는 앱 초기화를 생략한 테스트에만 동일한 런타임을 먼저 제공합니다.

13개 원작 파일은 추적 중인 원작 커밋과 바이트 단위로 같습니다. `upstream-boundary.json`의 `pristineEngine` 목록과 회귀 테스트가 이를 검사합니다. 이 검사는 원작 **소스 파일** 보존을 뜻합니다. 한국판 실행물에는 빌드 어댑터의 연결과 추가 콘텐츠가 포함됩니다. 아무 연결 없이 새로운 전투 동작이 저절로 작동한다는 의미는 아닙니다.

## 개발과 검증

`node tools/build.js --sin-seo`는 배포 파일과 `tools/cache/dev-app.js`를 함께 생성합니다. `dev.html`의 모듈 목록은 선언용이며, 브라우저는 이 개발 번들을 실행합니다. 원작 원본 스크립트를 직접 실행해 확장을 누락하는 개발/배포 차이를 피합니다. 파일을 수정했으면 다시 빌드한 뒤 개발 페이지를 확인합니다. 개발 번들과 QA 도구는 배포 패키지에 포함하지 않습니다.

`node kor/module-source.cjs`로 연결 문맥을 검사하고, `node kor/upstream-boundary.cjs`로 소스 경계를 검사합니다. CI는 전체 회귀 테스트와 함께 두 검사를 실행합니다. 자동 동기화 PR은 직접 수정 파일뿐 아니라 복원된 파일의 확장 연결과 겹치는 원작 변경도 표시합니다. 연결 문맥 일치만으로 의미상 호환을 보장하지 않으므로 관련 동작 테스트와 리뷰도 필요합니다.

## 데이터 호환

공개된 포켓몬 ID `1150`과 기술 ID `psycho-rush`는 그대로 유지합니다. 파일 위치·등록 방식을 옮겨도 기존 보유·시작 기술·강화·기술머신·랭킹 참조를 바꾸지 않습니다. 이번 변경에는 서버 수정·DB 마이그레이션·데이터 삭제가 없습니다.

이미 공개한 콘텐츠의 ID를 바꾸거나 팩을 지워서 기존 데이터를 정리하지 않습니다. 콘텐츠를 은퇴시킬 때도 기존 저장 참조를 해석할 수 있어야 합니다. 새로운 동작이 필요하면 한국판 컨트롤러와 관련 테스트를 추가하고 데이터의 `controller`로 연결합니다.

## 남은 분리

현재 원작 HTML·번역·독립 DB 연결·화면 코드 등 19개 파일에 직접 수정이 남아 있습니다. 이 문서는 전체 분리가 완료됐다는 선언이 아닙니다. 해당 수정은 기존 경계 목록으로 추적하며 별도로 분리해야 합니다. 원작 라이선스와 크레딧은 그대로 유지합니다.
