## 현재 구현

- 원본 Git 이력을 보존한 별도 저장소. 기존 `GuenohPark/pokesurvivor`는 변경하지 않습니다.
- 한국어 기본 언어, 한글 픽셀 폰트 갈무리, 게임 내 포켓몬 966종·특성·성격 한국어 명칭, 전체 영어 기준 UI 문구와 원작 업데이트 기록 번역.
- `kor/selfhost-db.js`가 독립 Node.js/PostgreSQL 백엔드의 로그인·회원가입·저장·삭제 API에 연결합니다.
- 비밀번호 4~128자, 이름 3~16자(문자·숫자·밑줄), 7일 HttpOnly 세션 쿠키. 한국어 독립판의 가입 화면에 규칙과 비밀번호 확인을 표시하며 불일치 시 요청을 보내지 않습니다.
- 한국판 업데이트 공지와 오픈 선물. 10회 뽑기권 100장·150,000코인을 서버에서 지급하고 기존 저장과 함께 기록합니다. 이미 받은 뽑기권은 재지급하지 않고 추가 코인만 받을 수 있습니다. 후원 링크는 독립 서버의 공지 설정에서 관리하며 후원 여부는 게임 혜택이나 선물 수령에 영향을 주지 않습니다.
- 저장 시 수정 번호를 검사하며, 번호가 달라지면 같은 계정의 서버 저장을 읽고 원작의 장부·컬렉션 병합 규칙으로 합쳐 최대 3회 재시도합니다. 응답만 유실된 저장은 내용을 비교해 확인하며, 여러 탭에서 새로 얻고 쓴 재화는 창별 장부에 기록합니다. 원작 저장 형식과 기존 장부·서버 보상은 유지합니다.
- 계속 저장하지 못해도 브라우저 백업은 갱신됩니다. 설정 → 저장·복구 도구에서 백업을 내보낸 뒤 저장을 재시도하세요. ‘서버 저장 다시 불러오기’는 이 기기의 변경을 버리는 수동 복구 수단이므로 백업 없이 누르지 마세요. 다른 탭에서 계정을 바꾼 경우 새 클라이언트는 서버의 계정 확인으로 잘못된 계정에 저장하는 것을 차단합니다.
- 원본 Firebase 설정 제거, 원본 서비스용 개인정보 안내 교체, API 응답의 PWA 캐시 저장 제외.
- 매일 한국 시간 05:17 upstream 확인 → 병합 브랜치·PR 생성 → CI. 충돌은 이슈로 남기며 수동 해결합니다.
- [Render + Neon 무료 시험 운영](https://pokesurvivor-kor.onrender.com/). 후속 배포는 서버 저장소의 `Manual Render deployment` 테스트와 `production` 환경 수동 승인을 거칩니다. 기존 SSH 배포는 `DEPLOY_ENABLED=false`로 유지합니다.

## 현재 지원 범위와 남은 과제

- 한국어 회귀 검사는 영어 기준 UI 1,563개, 포켓몬 966종, 성격·특성 이름, 원작 업데이트 기록을 대상으로 합니다. 새 upstream에서 추가되는 문구는 별도 번역이 필요하며, 미번역이 들어오면 테스트가 실패합니다.
- 친구 요청·수락·삭제, 접속 상태, 친구 초대와 최대 4인 실시간 협동을 독립 서버에 연결했습니다. 생존 기록은 개인전·협동전, 오늘·주간·월간·전체 기간, 전체·친구끼리 및 포켓몬별로 비교합니다. 기간은 한국 시간 기준입니다. 기존 미션의 날짜 기준은 유지합니다.
- Google 로그인, 비밀번호 복구, 원본 계정·저장 데이터 자동 이전은 지원하지 않습니다.
- 서버가 도전 시작·참가자·방장·실제 경과 시간·중복 제출을 검증합니다. 전투 시뮬레이션은 방장과 각 클라이언트가 담당하므로 완전한 부정행위 방지 서버는 아닙니다. 계정·친구·완료 기록은 PostgreSQL과 암호화 백업에 보관하지만, 진행 중인 협동 대기실은 서버 메모리에 있으므로 재시작하면 종료됩니다. 무료 서버는 접속자가 없을 때 절전하거나 재시작할 수 있습니다.
- 무료 시험 운영의 한도·매일 암호화 백업·복구 방법은 서버 저장소의 [Render + Neon 안내](https://github.com/guenoh/pokesurvivor-kor-server/blob/main/RENDER-NEON.md)를 따릅니다. 개인 도메인과 정식 운영 정책은 별도 확정이 필요합니다.
- 이전 대화의 `/mnt/data/pokesurvivor-selfhost-starter.zip`은 이 작업에서 실제 파일을 확보하지 못했습니다. 재사용했다고 가정하지 않았습니다.

## 개발

Node.js 24와 pnpm 11.25.0을 사용합니다.

```sh
pnpm install --frozen-lockfile --ignore-scripts
node --test tests/*.test.cjs
node tools/build.js --sin-seo
node kor/coverage.cjs
node kor/package.cjs
```

`dev.html`이 원본이며 `index.html`은 생성물입니다. 원본 게임 코드는 가능한 그대로 두고 독립판 코드를 `kor/`에 둡니다. DB 모듈에 저장 데이터 초기화용 `openSelfhost` 연결점, 언어·빌드 모듈에 한국어 등록을 추가했습니다. 소수 원본 파일 변경도 upstream과 충돌할 수 있으므로 무충돌 자동 병합을 보장하지 않습니다.

정적 파일만 GitHub Pages에 올려도 독립 계정은 동작하지 않습니다. 프런트엔드와 `/api`를 같은 HTTPS 출처로 제공해야 합니다. 배포 구성은 서버 저장소 [운영 가이드](https://github.com/guenoh/pokesurvivor-kor-server/blob/main/DEPLOYMENT.md)를 따릅니다.

### 모바일 화면 크기

설정 → 그래픽 → 메뉴 크기에서 자동·80%·90%·100%·110%를 선택할 수 있습니다. 자동은 작은 화면에서 85%로 표시합니다. 선택은 기기별 브라우저에 저장되며, 게임 월드와 터치 조작 범위는 바뀌지 않습니다. 사파리 주소창이 차지하는 높이를 반영하고 화면 확대 제스처는 유지합니다. 슬롯 한글은 도트 캔버스와 분리해 화면 해상도로 표시합니다.

### 한국어 번역 점검

`node kor/coverage.cjs`는 기존 영어 UI 키뿐 아니라 실제 게임 데이터의 한국어 출력도 검사합니다. 특성 이름·모든 타입별 특성 효과·성격·포켓몬·기술 이름과 설명·강화·진화·도구·업적·원작 변경 기록 및 대표 운영 문구를 포함합니다. 결과는 `kor/translation-coverage.json`에 기록되며, 누락 시 CI가 실패합니다. 전체 브라우저 경로를 실행하는 검사는 아닙니다. 원작 운영자·클라우드 안내 등 비활성 화면도 운영 문구 표본에 포함합니다.

`AR시스템`, `DD래리어트`, `폴리곤Z`와 `HP`·`KO`는 한국어 표기 안의 영문자를 유지합니다. 2026-10-23 기준 특성 271개와 성격 25개의 이름은 [PokeAPI 한국어 명칭 데이터](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv)와 대조했습니다. 기술은 내부 ID와 원작 표시명이 다른 경우가 있으므로 표시명을 기준으로 번역합니다.

### 한국판 기술 역할 평가

레벨업의 새 기술·강화·진화, 기술 연결, 시작 기술 1·2 및 기술머신 사용 목록에 두 개의 참고 등급을 표시합니다. 몬스터볼 세 개는 무리 사냥, 왕관을 쓴 보스 얼굴은 보스전입니다. 등급 버튼은 기술 선택과 별도로 평가 설명을 엽니다. 보조 기술은 직접 공격 등급 대신 `보조 기술`로 표시합니다.

`kor/move-ratings.js`는 공격 방식별 명중·범위 계수를 이용하는 휴리스틱입니다. 전투 시뮬레이션이나 측정 DPS, 원작의 공식 티어가 아닙니다. 가까이 모인 적 최대 세 마리와 중립 상성의 보스 한 마리를 각각 가정하고, 현재 포켓몬이 배울 수 있는 공격 기술을 같은 레벨·진화 단계에서 비교합니다. 각 역할의 최고 점수 대비 80/60/40/22% 이상을 S/A/B/C, 그 미만을 D로 표시합니다. 선택지 세 장만 바뀌어도 등급이 달라지지 않도록 비교 풀은 배울 수 있는 기술 전체를 사용합니다.

포켓몬의 성격을 반영한 물리·특수 능력치, 단일 타입 보너스, 현재 공격 강화·급소율·공격 간격, 검토한 특성의 직접 공격 보정을 반영합니다. 메뉴의 시작 기술·기술머신 평가는 포켓몬의 현재 성격·특성과 영구 강화 기준이며, 탐험 중 평가는 실제 플레이어 상태를 사용합니다. 특성의 시작·타격·처치 훅은 실행하지 않습니다. 검토한 순수 피해 훅만 분리된 스냅숏에서 읽고, 의욕의 무작위 보정은 기대값으로 계산합니다. 새 특성 훅은 검토 전까지 직접 보정에 포함하지 않습니다.

상대 타입·방어력·이동 경로, 상태이상 추가 피해·회복·생존 효과, 기술 연결 조합은 등급에서 제외합니다. 범위·명중 계수는 실제 플레이 자료로 조정할 수 있으며, `tests/move-ratings.test.cjs`는 모든 공격 방식·레벨·진화, 연쇄 공격의 단일 대상 처리, 능력치·특성 반영, 플레이어 상태 보존 및 전투 난수 비소비를 검사합니다.
